# 뚱보주름메뚜기 현장조사 야장 (PWA)

휴대폰 브라우저에서 열어 "홈 화면에 추가"하면 앱처럼 아이콘으로 설치되는 오프라인 현장조사 야장입니다.
모든 기록과 사진은 **각자 휴대폰의 IndexedDB에만 저장**되며 서버로 전송되지 않습니다.

## 포함 기능
1. 접속 시 조사일시 자동입력, GPS 좌표 자동획득 + Open-Meteo(무료, 키 불필요) 기상 자동입력, Nominatim 역지오코딩으로 조사지역명(행정구역) 자동입력
2. "미소서식지 및 개체 클로즈업 촬영(격자)" 시 실시간 흰색 격자 오버레이(촬영 중·저장본 모두 표시), 촬영거리 기준 격자 1칸 실크기 자동계산, scale bar 동시촬영 안내
3. "방위별 전경사진 촬영" 버튼 → 방위(나침반) 센서로 방위를 측정한 뒤(방위 측정 중에는 "휴대폰 뒷면이 지면과 수평을 이루게 하십시오" 안내 표시) 8방위 중 하나를 선택하면 휴대폰 기본 카메라 앱이 열려 촬영. 센서가 없거나 부정확한 기기에서는 8방위 버튼으로 직접 선택 가능
4. 저장된 모든 기록·사진을 한 번에 표준 형식 PDF로 내보내기 (개별 기록 PDF도 가능), 나눔고딕 폰트를 임베드해 한글이 깨지지 않도록 처리
5. 오프라인 서비스워커 캐싱 → 인터넷 연결 없는 현장에서도 앱 실행/기록/PDF 저장 가능 (GPS·기상·지역명 자동입력과 PDF 한글폰트 최초 로딩만 인터넷 필요, 이후 캐시로 오프라인 동작)

## GitHub Pages로 배포하는 방법

1. GitHub에 새 저장소 생성 (예: `grasshopper-survey`)
2. 이 폴더의 5개 파일을 저장소 루트에 업로드
   - `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`
3. 저장소 **Settings → Pages** 이동
4. Source를 `Deploy from a branch` → Branch `main` / `/(root)` 선택 후 저장
5. 몇 분 후 `https://[깃허브아이디].github.io/grasshopper-survey/` 로 접속 가능

## 휴대폰에 설치하기
- **Android(Chrome)**: 사이트 접속 → 상단 "홈 화면에 추가" 버튼 또는 브라우저 메뉴 → "앱 설치"
- **iPhone(Safari)**: 사이트 접속 → 하단 공유 버튼(⬆️) → "홈 화면에 추가"

설치 후에는 홈 화면 아이콘으로 바로 실행되며, 오프라인에서도 동작합니다.

## 알아두어야 할 제약
- **카메라 권한**: 클로즈업 격자 촬영은 웹 카메라 API(getUserMedia)를 사용하므로 최초 실행 시 카메라 권한 허용이 필요합니다. HTTPS(GitHub Pages는 기본 제공)에서만 동작합니다.
- **격자 정확도**: 격자 1칸의 실제 크기는 "촬영거리 × 카메라 화각" 기반의 근사치입니다. 기기별 실제 화각이 조금씩 달라 오차가 있을 수 있어, 처음 한 번은 자로 잰 물체를 촬영해 고급설정의 '카메라 화각' 값을 보정해두는 것을 권장합니다.
- **방위 센서 정확도**: 방위(나침반) 값은 기기의 지자기 센서를 사용합니다. iOS Safari는 비교적 정확한 절대방위를 제공하지만, 일부 Android 기기·브라우저는 값이 부정확하거나 아예 지원하지 않을 수 있습니다. 이런 경우 8방위 버튼으로 직접 선택해 촬영을 진행하면 됩니다. iOS는 최초 사용 시 방위 센서 접근 권한을 한 번 허용해야 합니다.
- **파노라마 자동실행 불가**: "방위별 전경사진" 기능도 방위 측정 후에는 네이티브 카메라 앱을 여는 방식입니다. 브라우저는 카메라 앱의 특정 촬영모드(파노라마 등)를 직접 실행시킬 권한이 없어, 필요시 카메라 앱 안에서 사용자가 직접 모드를 전환해야 합니다.
- **PDF 한글 폰트**: PDF 내 한글이 깨지지 않도록 나눔고딕 폰트를 최초 내보내기 시 온라인으로 1회 내려받아 캐싱합니다. 완전히 오프라인인 첫 사용(인터넷 연결 없이 처음 PDF를 시도하는 경우)에는 폰트를 불러올 수 없다는 안내가 뜨니, 최초 1회는 인터넷이 연결된 상태에서 PDF를 한 번 내보내 두는 것을 권장합니다. 이후에는 오프라인에서도 정상 동작합니다.
- **데이터 백업**: 모든 데이터는 브라우저 로컬 저장소(IndexedDB)에만 있습니다. 브라우저 데이터를 삭제하거나 기기를 바꾸면 기록이 사라지므로, 현장 조사 후 "전체 기록 PDF로 내보내기"로 주기적 백업을 권장합니다.
